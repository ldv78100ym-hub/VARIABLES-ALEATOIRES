Variables Aléatoires et Modélisation

1. Les Variables Aléatoires Discrètes

A. Définition

Lorsqu'on réalise une expérience aléatoire, on s'intéresse souvent à un résultat chiffré (un gain à un jeu, la somme de deux dés, le nombre de pièces défectueuses, etc.).

Variable Aléatoire : Une variable aléatoire (souvent notée $X$, $Y$ ou $Z$) est une fonction mathématique qui associe un nombre réel à chaque issue possible d'une expérience aléatoire. On dit qu'elle est discrète si elle prend un nombre fini (ou dénombrable) de valeurs isolées.

Exemple d'introduction : Imaginons un jeu où l'on tire une boule dans une urne contenant $10$ boules : $1$ boule rouge (qui rapporte $8$€), $2$ boules bleues (qui rapportent $3$€) et $7$ boules noires (qui font perdre $2$€). La variable aléatoire $X$, représentant le gain algébrique du joueur, prend les valeurs : $$x_1 = 8 \quad ; \quad x_2 = 3 \quad ; \quad x_3 = -2$$

B. Loi de Probabilité

Définition : Définir la loi de probabilité d'une variable aléatoire discrète $X$, c'est déterminer toutes les valeurs possibles $x_1, x_2, \dots, x_n$ prises par $X$, et calculer la probabilité $P(X = x_i)$ associée à chacune de ces valeurs.

Propriété fondamentale : La somme des probabilités de toutes les valeurs possibles est strictement égale à $1$.

$$\sum_{i=1}^{n} P(X = x_i) = P(X = x_1) + P(X = x_2) + \dots + P(X = x_n) = 1$$

Application sur l'exemple :

  • $P(X = 8) = \dfrac{1}{10}$ (Une seule boule rouge sur 10)
  • $P(X = 3) = \dfrac{2}{10} = \dfrac{1}{5}$ (Fraction irréductible)
  • $P(X = -2) = \dfrac{7}{10}$
Valeurs $x_i$ $-2$ $3$ $8$
$P(X = x_i)$ $\dfrac{7}{10}$ $\dfrac{1}{5}$ $\dfrac{1}{10}$

C. Indicateurs de Position et de Dispersion

L'Espérance Mathématique $E(X)$ : Elle représente la valeur moyenne théorique que l'on peut espérer obtenir si l'on répète l'expérience un très grand nombre de fois.

$$E(X) = \sum_{i=1}^{n} x_i \times P(X = x_i)$$

Calcul sur l'exemple : $E(X) = -2 \times \left(\dfrac{7}{10}\right) + 3 \times \left(\dfrac{1}{5}\right) + 8 \times \left(\dfrac{1}{10}\right) = -\dfrac{14}{10} + \dfrac{6}{10} + \dfrac{8}{10} = 0$. (Le jeu est équitable).

La Variance $V(X)$ et l'Écart-Type $\sigma(X)$ : Ils mesurent la dispersion des valeurs autour de l'espérance. Plus ces indicateurs sont grands, plus les résultats fluctuent.

$$V(X) = E(X^2) - (E(X))^2$$

Calcul sur l'exemple : $V(X) = (-2)^2 \times \dfrac{7}{10} + (3)^2 \times \dfrac{1}{5} + (8)^2 \times \dfrac{1}{10} = 4 \times \dfrac{7}{10} + 9 \times \dfrac{2}{10} + 64 \times \dfrac{1}{10} = \dfrac{110}{10} = 11$.

L'écart-type est la racine carrée de la variance : $\sigma(X) = \sqrt{V(X)}$. Dans l'exemple : $\sigma(X) = \sqrt{11}$.

Propriétés : Pour tous nombres réels $a$ et $b$ :

  • $E(aX + b) = a \times E(X) + b$ : L'espèrence est dite linéaire
  • $V(aX + b) = a^2 \times V(X)$

2. La Loi de Bernoulli

Une épreuve de Bernoulli est une expérience aléatoire qui ne comporte que deux issues possibles :

  • Le Succès (noté $S$), de probabilité $p$.
  • L'Échec (noté $\overline{S}$), de probabilité $1 - p$.

Loi de Bernoulli : Une variable aléatoire $X$ suit une loi de Bernoulli de paramètre $p$ si elle associe la valeur $1$ au succès et $0$ à l'échec. On a alors : $P(X = 1) = p$ et $P(X = 0) = 1 - p$.

Propriétés : En appliquant les formules générales de la partie 1 à ces deux uniques valeurs, on démontre que l'espérance est $E(X) = p$ et la variance est $V(X) = p(1-p)$.
